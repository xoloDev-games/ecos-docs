# Soporte

## Contacto

- **Email:** [xoloDev.games@gmail.com](mailto:xoloDev.games@gmail.com)
- **Documentación:** este sitio
- **Repositorio de documentación:** [github.com/xoloDev-games/ecos-docs](https://github.com/xoloDev-games/ecos-docs)

Tiempo de respuesta objetivo: **24–48 horas laborables**. Los fines de semana y festivos
pueden tardar más.

## Antes de escribir

Incluye siempre:

1. Versión exacta de Unity (`6000.3.19f1`, por ejemplo).
2. Versión de `com.unity.ai.inference`.
3. Backend usado: `GPUCompute`, `GPUCommandBuffer` o `CPU`.
4. Si usas modelo propio, versión y formato (`FP16`, `INT8`, otro).
5. Log completo de la Consola, no sólo la última línea.
6. Pasos mínimos para reproducirlo.
7. Qué esperabas que ocurriera y qué ocurrió.

## Qué cubre el soporte

- Errores de integración con Unity.
- dudas sobre configuración, scopes, cantidades, memoria y reacciones;
- problemas con la importación del modelo;
- errores en la documentación.

## Qué no cubre

- Diseño narrativo completo de tu juego.
- Modelos de IA de terceros distintos del recomendado.
- Modificaciones profundas del Core que rompan la API pública.
- Soporte de plataformas no listadas en los requisitos.

## Documentación con errores

Si encuentras un enlace roto, una errata o un ejemplo que no compila, abre un issue en el
repositorio público de documentación. Incluye la página y el fragmento exacto.
